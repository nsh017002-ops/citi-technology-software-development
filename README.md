# Citi Technology Software Development Job Simulation

A practical software development project completed as part of the **Citi Technology Software Development Job Simulation** on Forage.

The simulation involved completing four practical tasks covering system design, credit risk modeling, web data querying, and live data visualization.

## Tasks Completed

### 1. Loan State Diagram

Created a state diagram representing the loan management workflow.

The workflow includes:

- Draft
- Under Review
- Approved
- Disbursed
- Closed
- Rejected

**File:** `loan-state-diagram.drawio`

---

### 2. Credit Risk Modeling Proposal

Developed a proposal for integrating a machine learning-powered credit risk modeling system into a loan management workflow.

The proposal covers:

- Data Requirements
- Data Outputs
- Model Architecture
- Risks and Challenges

The proposed architecture considers Gradient Boosting Machines such as XGBoost/LightGBM along with explainability approaches such as SHAP.

**File:** Credit Risk Modeling Proposal

---

### 3. Web Data Query

Completed a practical task involving querying data from the web using a programming notebook.

**File:** `web-data-query.ipynb`

---

### 4. Live Data Visualization

Implemented a live data retrieval and visualization workflow using a programming notebook.

The implementation includes:

- Java
- Twelve Data API
- Live data retrieval
- Data processing
- Data visualization

**File:** `live-data-visualization.ipynb`
